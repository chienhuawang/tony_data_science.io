Key Core Features
  • Serverless Scale-to-Zero: Unified backend combining FastAPI & MCP SSE service packaged into a single Docker image on Google Cloud Run to keep idle costs at absolute zero.

Core Components Role Description
Google Cloud Run (Unified Backend & ETL Jobs): Runs FastAPI web servers inside Docker, automatically scaling from 0 to 10 instances. Daily ETL processes (triggered at 14:30 UTC+8 by Cloud Scheduler) download, parse, and upload Taiwanese stock metrics to Google Cloud Storage.
Google Cloud Firestore (Storage Layer): Holds user profiles, Stripe subscriptions, billing credentials, and API tokens. Utilizes a single-field index on mcp_api_key to ensure sub-millisecond O(1) query lookups.
Google Cloud Storage (Data Caching): Serves as the high-availability data lake. Raw and clean CSV datasets containing historical prices and quantitative metrics are read by the MCP backend as a fallback cache on local memory.

Key Lifecycle Security
  • Cryptographic Random Keys: Keys use a prefix nv_sec_live_[A-Za-z0-9_]{48} generated using Python's secure secrets package during Firebase user creation.
  • Instant Key Revocation & Rotation: An API rotation button allows users to immediately override old keys on Firestore. Any active SSE stream on the older key receives a terminal close packet and closes gracefully.

GCP Serverless Production Deployment Steps

Step 1: Containerization & Artifact Registry Push

# Build Docker Image
docker build -t gcr.io/[PROJECT_ID]/tw-stock-backend:latest ./tw_stock_mcp_web/backend

# Push container to Google Artifact Registry
docker push gcr.io/[PROJECT_ID]/tw-stock-backend:latest

Step 2: Serverless Cloud Run Deployment

gcloud run deploy tw-stock-backend \
  --image gcr.io/[PROJECT_ID]/tw-stock-backend:latest \
  --platform managed \
  --region asia-east1 \
  --allow-unauthenticated \
  --update-secrets=STRIPE_SECRET_KEY=stripe-secret-key:latest \
  --update-secrets=STRIPE_WEBHOOK_SECRET=stripe-webhook-secret:latest \
  --set-env-vars=GCS_BUCKET_NAME=[YOUR_DATA_BUCKET_NAME],FIREBASE_PROJECT_ID=[YOUR_PROJECT_ID]

Step 3: Point Reset Automation (Cloud Scheduler)

Configure a Cloud Scheduler cron triggering the daily quota reset endpoint at 00:00 UTC+8:

gcloud scheduler jobs create http reset-points-daily \
  --schedule="0 0 * * *" \
  --time-zone="Asia/Taipei" \
  --uri="https://tw-stock-backend-xxxxxx.a.run.app/api/system/reset-daily-points" \
  --http-method=POST \
  --headers="Authorization=Bearer [OIDC_TOKEN_OR_SECRET_KEY]"
